# Documentación y Auditoría de Base de Datos - Contrabajo

Este repositorio contiene la documentación, gestión y recursos técnicos del proyecto **Contrabajo**, desarrollado en el contexto de la asignatura *Taller Aplicado de Programación (TPY1101)*.

El objetivo del repositorio es centralizar la información necesaria para el diseño, desarrollo, despliegue y validación de la solución tecnológica, siguiendo buenas prácticas de ingeniería de software y control de versiones.

---

## 📌 Descripción del Proyecto

**Contrabajo** es una aplicación móvil orientada a la intermediación de servicios técnicos, permitiendo conectar clientes con trabajadores especializados mediante una plataforma tipo marketplace.

La solución está diseñada bajo una arquitectura moderna basada en:
- Microservicios en Java (Spring Boot)
- Aplicación móvil nativa en Kotlin
- Infraestructura en la nube utilizando Microsoft Azure (modelo PaaS)

---

## 📁 Estructura del Repositorio

El repositorio se organiza en tres carpetas principales:

### 📂 Documentación
Contiene todos los artefactos de análisis, diseño y definición del sistema:
- Informe de avance del proyecto (EP1 y EP2)
- Diagramas UML (casos de uso, clases, etc.)
- Modelo Entidad-Relación (MER)
- Mockups y diseño de interfaz
- Documentación de requerimientos (RF y RNF)

---

### 📂 Producto
Incluye los recursos técnicos asociados al desarrollo:
- Scripts de base de datos (.sql)
- Procedimientos almacenados
- Estructura de la base de datos
- Código fuente o enlace al repositorio principal del proyecto

---

### 📂 Gestión
Contiene documentos administrativos y de organización del proyecto:
- Documento de registro de software (1.1.2)
- Planificación del proyecto (Carta Gantt)
- Archivo de integrantes del equipo
- Evidencia de gestión y control del desarrollo

---

## ⚙️ Stack Tecnológico

- **Frontend:** Kotlin (Android nativo)
- **Backend:** Java + Spring Boot (Microservicios)
- **Base de Datos:** Azure SQL Database
- **Infraestructura:** Microsoft Azure (PaaS)
- **Control de Versiones:** GitHub

---

## ☁️ Infraestructura y Despliegue

El sistema se implementa en un entorno cloud utilizando **Microsoft Azure**, permitiendo:

- Alta disponibilidad de servicios
- Escalabilidad según demanda
- Administración simplificada de la base de datos
- Integración continua con repositorios de código
